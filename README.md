📊 Overview

This project presents an interactive Power BI Project Portfolio Dashboard that provides an executive-level view of project performance across the organization and departments.
It enables data-driven monitoring of progress, budget, schedules, and risks.

🎯 Objectives

Track overall project completion and performance

Monitor schedule and budget variance

Assess delivery and financial health

Identify and analyze project risks

Support strategic decision-making

🚀 Key Features

Executive KPIs (budget, active projects, completion %)

Project portfolio overview with status indicators

Schedule and budget variance analysis

Risk distribution and risk radar visualization

Burn-up chart and project timeline

Strategic alignment matrix

Interactive slicers for filtering by department, status, risk, and time
